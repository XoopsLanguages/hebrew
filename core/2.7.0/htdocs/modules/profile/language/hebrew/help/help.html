תיאור

מודול הפרופיל מיועד לניהול שדות פרופיל משתמש מותאמים אישית.

התקן/הסר התקנה

אין צורך באמצעים מיוחדים, עקוב אחר תהליך ההתקנה הסטנדרטי - חלץ את התיקיה /profile לספריית ../modules. התקן את המודול דרך Admin -> מודול מערכת -> מודולים.

הוראות מפורטות על התקנת מודולים זמינות ב- מדריך התפעול של XOOPS

הוראות הפעלה

כדי להגדיר מודול זה עליך:

  • הגדר את ההעדפות שלך עבור המודול (ראה 'העדפות') ובאופן אופציונלי לחסום הפרופיל אם אתה מתכוון להשתמש בו (ראה 'בלוקים').
  • ערוך קטגוריות קיימות או הוסף קטגוריות חדשות.
  • ערוך שדות קיימים או הוסף שדות חדשים. כאן תוכל לציין אילו שדות יהיו גלויים באיזו קטגוריה, ואם הם יהיו גלויים במהלך רישום המשתמש.
  • הגדר את סדר שלבי הרישום.
  • ולבסוף, אתה יכול להגדיר הרשאות לשדות בודדים - אילו ניתנים לעריכה, אילו ניתנים לחיפוש.

אמצעים נגד דואר זבל

כדי למזער רישום דואר זבל, בצע את הפעולות הבאות:

  • עבור למודול Protector ב-Admin, עבור אל העדפות, ולאחר מכן בתחתית, באפשרות זו: "עצרו את הספאם בפורום" בודק נתוני POST מול שולחי דואר זבל הרשומים במסד הנתונים www.stopforumspam.com.
    הגדר אותו ל"חסום את ה-IP (ללא הגבלה)"

  • ב-/class/captcha/config.php, ודא שהמצב מוגדר כ"טקסט":

    return $config = array(
    'disabled' => false, // השבת CAPTCHA
    'mode' => 'טקסט', // מצב ברירת מחדל, אתה יכול לבחור 'טקסט', 'תמונה', 'recaptcha' (דורש מפתח API)
    'name' => 'xoopscaptcha', // captcha name
    'skipmember' => נכון, // דלג על בדיקת CAPTCHA עבור חברים
    'maxattempts' => 10, // מקסימום ניסיונות עבור כל הפעלה
    );

  • במודול הפרופיל, עבור אל Admin ובשלב הבסיסי הממוקם בכתובת:
    /modules/profile/admin/step.php?id=1
    הגדר את "שמור לאחר עצירה" ל"לא"


  • בהעדפות פרופיל, הגדר את האפשרות "השתמש ב-Captcha לאחר שלב הרישום השני" ל-"כן" (זו ברירת המחדל)
